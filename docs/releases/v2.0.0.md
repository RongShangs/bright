# v2.0.0 · 背屏策略与可选 LSP 接入

## 更新内容

- 新增两个可选 LSPosed 开关：阻止背屏 AOD 暗光自动息屏、阻止背屏 AOD 遮挡自动息屏，两项独立控制。
- 主面板保持原有短卡片比例；右侧中间按钮改为黄色“背屏策略”入口。永不息屏移至策略页，与 LSP 开关按 Root / LSP 分组，移除左侧旧 LSP 入口。
- 策略页支持深浅色、滚动和返回导航，明确显示连接、保存失败与守护异常。酷安入口改为“酷安@戎Shangs”。
- 修复 Service 主题缺失导致开关测量崩溃的问题，补充界面启动、短卡片高度、三个开关、返回和横屏大字体回归测试。
- LSP 配置通过框架远程配置同步，写入失败不显示成功；恢复系统控制同时尝试关闭两项 LSP 开关，未全部恢复时明确提示。
- 保留面板关闭后主动退出主进程的机制，并覆盖仅配置通道拉起进程时的空闲退出。
- 守护异常时，开关保留系统实际设置以便关闭，磁贴不再把残留的无限超时误报为常亮正常。

## Root 与 LSP 的区别

- 亮度、AOD 和永不息屏仍只需 Root，不强制安装 LSP。
- Root 永不息屏沿用原有 C 守护，检测息屏后尝试唤醒并保持活跃画面，可能短暂黑屏，耗电较高。
- LSP 两项仅拦截背屏 AOD 的指定传感器与暗光定时策略，不把 AOD 改成活跃画面，不拦截主屏通话感应、电源键、双击、热保护或其他超时。
- LSP 仅注入已有背屏中心，不新增 Service、线程、轮询或 WakeLock。原有 C 程序不变，仅调亮度仍正常每 4 秒检查，不增加显示查询或唤醒锁。
- 提高亮度、减少息屏都会增加屏幕耗电与烧屏风险；没有零功耗或固定内存占用保证。

## 启用与兼容

1. 安装后授予 Root 和桌面入口所需的悬浮窗权限。
2. 需要 LSP 功能时，使用支持 libxposed API 101、远程配置的 LSPosed，启用“背屏控制”模块，作用域仅选“背屏中心” `com.xiaomi.subscreencenter`。
3. 首次启用或更新模块后重启手机，让背屏中心加载新代码；覆盖安装 APK 不会替换进程中已加载的模块。仅切换开关不需要重启。
4. 在“背屏策略”页分别开启需要的功能。已息屏时先重新唤醒；卸载前关闭策略并恢复系统控制。
