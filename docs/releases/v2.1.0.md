# v2.1.0 · 切页动画与 LSP 兼容适配

## 重要：包名变更，需要迁移安装

应用包名从 `brightnesslock.rongshangs.top` 调整为 `top.rongshangs.brightnesslock`。签名未变，但 Android 将它视为不同应用，不能覆盖旧版（包括此前旧包名的 2.1.0 测试包）。

1. 在旧版关闭两项 LSP 策略并点“恢复系统控制”，确认恢复成功。
2. 在 LSPosed 中停用旧模块，卸载旧包。不要同时启用两个包的模块。
3. 安装新包，重新授予 Root 和悬浮窗权限，重新添加控制中心磁贴。
4. 需要 LSP 时启用新模块，作用域仅选“背屏中心” `com.xiaomi.subscreencenter`，重启手机后重新设置策略。旧版配置不自动迁移。

## 更新内容

- 基础面板与背屏策略页加入 220ms 双向淡入淡出与轻微位移动画；切页不重置背景模糊，系统关闭动画时直接切换。
- 切页期间阻止重复触控，快速返回、关闭和界面销毁会完成并清理旧动画，不留下透明触摸层或回调。
- 从 DozeService 的字段类型解析传感器与定时器实现，不再依赖两个固定混淆短名；保留严格结构校验、独立定时器隔离和失败透传，安装日志记录真实实现类。
- 应用、组件、磁贴动作、自定义控件与 LSP 入口统一使用新包名，为独立模块分发仓库准备资料。原源码仓库继续保留在 RongShangs/bright。
- 使用范围说明扩展至小米 17 / 18 系列 Pro、Pro Max 背屏机型；具体固件仍需验证，并非全设备兼容保证。
- Root 亮度、AOD、永不息屏、C 守护与空闲退出机制保持不变，仅亮度模式仍正常每 4 秒检查，不增加显示查询或唤醒锁。

## 启用与验证范围

LSP 功能需要支持 libxposed API 101、远程配置的 LSPosed。两个开关仅拦截背屏 AOD 的暗光、遮挡路径，不干涉主屏感应、电源键、双击、热保护或其他超时；Root 永不息屏为独立功能。

42 项 JVM 单元测试、15 项原生解析/边界检查通过；Release 构建、签名校验成功，lint 无错误（74 warnings、2 hints）。新增测试包含辅助类结构变化、包名组件一致性、动画中间帧、快速返回、取消清理与系统禁用动画。

官网 index 已检查 320 / 390 / 768 / 1440 宽度及深浅色：无页面横向溢出、无损坏图片，两个下载入口均指向本次签名 APK。

旧固件的功能验证沿用 2.0.0 用户反馈。新版背屏中心 `RELEASE-1.0.2609231642` 的适配依据用户提供的结构报告，本轮未独立取得厂商 APK、未连接设备完成新包名及动画真机验收，未实测长期功耗。未知结构保留系统行为，详细证据边界见源码仓库 docs/2.1-hook-compatibility.md。
